## 任务

【命令九｜升级底座版本号】

背景：经历了插件全局化、install.bat 重构、启动器重写等重大架构变更，底座版本号（目前是 1.1.0）需要按语义化规范进行升级，建议升到 1.2.0（或 2.0.0，由你根据 breaking change 的程度决定，建议 1.2.0）。

要求：
1. 全局排查版本号单源（Single Source of Truth）位置：
   - 检查 app/main.py 或 app/core/config.py 里的 VERSION 常量。
   - 检查 pyproject.toml / requirements.txt 等工程文件（如果有）。
   - 检查 build_release.bat 脚本里打的包名（如 jiuzhang-operator-v1.1.0.zip）。
   - 检查 README.md 文档里的版本号显示。
   - 检查 tests/test_version_consistency.py 里的版本断言。
2. 将所有单源版本号统一升到新版（如 1.2.0），并同步修改测试用例。
3. 跑全量回归 + 快门禁（必须全绿）。
4. 打一个最新的发行包，确认解压后的包名、/healthz 接口返回的 version 字段均为最新版本号。
5. 提交 commit 并与上一轮的启动器一起 push 到远端，出回传单。

## 边界

- 不得扩大改动面；发现与 `docs/AGENTS.md` 冲突先停下报告。
- 涉及前端必须在浏览器里走真人路径；涉及插件必须过三查。
- 一个阶段一个 commit，测试不绿不许 commit。
