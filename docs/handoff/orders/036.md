## 任务

【命令十｜重构 install.bat：纯净发行包与双文件夹平级结构】

背景：老师实测发现，现在的 install.bat 直接下载 main 分支源码，解压后满屏都是 tests、tools、.qoder 等开发文件，而且把底座和插件混在了一个文件夹里，不符合物理分离的设计。

要求：
1. 修改 install.bat 的下载源（拉取纯净包）：
   - 底座：不再拉取 main 分支源码 zip，改为拉取 Releases 里的纯净发行包（例如 jiuzhang-operator-v1.2.0.zip）。如果目前没配置自动发包，可以在脚本里指定最新 Release 的下载链接，或者让脚本从 latest/download 获取。
   - 插件：依然可以拉取 jiuzhang-plugins 的 main 分支 zip。
2. 重构解压与目录结构（同级双文件夹）：
   在空文件夹双击 install.bat 后，要求生成如下结构：
   <当前目录>/
     ├── jiuzhang-operator/    (底座，含 start.bat, app, static 等)
     ├── jiuzhang-plugins/     (插件，含 src/org.jiuzhang.*)
     └── 如何迁移旧数据.txt
   实现方式：
   - 把底座包解压并放到 %~dp0jiuzhang-operator\。
   - 把插件包解压并放到 %~dp0jiuzhang-plugins\（注意：不要只把 src 拷出来，整个仓库结构保留，这样底座可以通过同级探测自动找到 ../jiuzhang-plugins/src）。
3. 修改启动调用：
   - 安装完成后，调用 %~dp0jiuzhang-operator\start.bat 启动服务。
   - 确认底座启动时，能完美识别同级目录下的 jiuzhang-plugins/src 里的插件。
4. 迁移说明文件调整：
   - 生成的文本说明里，提示老师数据位置为 jiuzhang-operator/data/。
5. 测试与验证：
   - 在空文件夹跑一遍，截图展示最终干净的目录树。
   - 验证服务能正常拉起，且插件全部加载。
   - 跑全量回归与门禁，提交推送。

## 边界

- 涉及前端必须在浏览器里走真人路径；涉及插件必须过三查。
- 一个阶段一个 commit，测试不绿不许 commit。
