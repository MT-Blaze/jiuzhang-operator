## 一、判据与结论

| 口径 | 命中题数 | 说明 |
|---|---|---|
| 旧库声明多选 → 新库却判单选 | 26 | v1 尺子（只认「【答案】同一行」）看不到真字母 |
| **答案区可确定、需改判多选** | **17** | 主尺子：答案区取字母 ≥2 |
| **正文尾句「故选：XX」补判、需改判多选** | **2** | 旧库无【答案】标记，只有【解析】+尾句 |
| **需纠偏合计（单选→多选）** | **19** | 17 + 2 |
| 旧库选择题被降级成解答题 | 2 | 选项内嵌在题干正文里，须先补选项 |
| 选择题但旧库 answer_markdown 完全为空 | 18 | **数据缺失**，现库以硬编码 A 兜底 |
| 选择题但答案区与尾句都取不到字母 | 15 | 有正文无结论句，须人工定 |

主尺子定义：**答案区 = 第一个【解析】/【详解】之前** → 剥 `\textbf{}` 等排版壳 → 去掉 `$...$` 数学段 → 取连续的 A–H 字母序列。辅尺子：正文末句 `故选/因此选 + 字母`。
新库当前分布 `{single 186, multiple 55, fill 86, solution 129}`；旧库声明分布 `{single 161, multi 82, fill 86, detailed 127}`。两库选择题合计都含 243 题。
