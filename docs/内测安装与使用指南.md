# 九章算子 · 内测安装与使用指南

> 面向**不懂技术的老师**。全程只需「双击」和「用记事本改几个字」，**不需要敲任何命令**。
> 遇到看不懂的词，直接跳到最后的「常见问题」。

---

## 〇、这是什么？

九章算子是一个**装在你自己电脑上**的数学题库工具。它的特点：

- **完全本地**：你的题目存在你自己电脑里，不上传到任何云端，断网也能用。
- **永久免费**：不要账号、不要激活码、不会到期、不会弹窗催费。
- **AI 是可选的**：填了 AI 密钥，就能用「导入原卷 → 自动拆题」；不填，其它功能照常能用。

你会用到三个东西：

1. 一个**浏览器页面**（`http://127.0.0.1:65496/e`）——你实际操作的界面。
2. 一个 **`.env` 文件**——填 AI 密钥的地方（用记事本改）。
3. 一个**日志文件**（`data\launcher.log`）——启动出问题时看它，服务在后台静默运行，不再有黑窗口要留着。

---

## 一、准备工作：装一次 Python（只需一次）

九章算子靠 Python 运行。电脑上装过一次以后，就不用再装了。

1. 打开浏览器，访问 **https://www.python.org/downloads/**
2. 点黄色的 **「Download Python 3.x.x」** 按钮下载。
3. 双击下载好的安装包。
4. ⚠️ **最重要的一步**：安装界面**最下面**有个勾选框
   **「Add Python to PATH」**（或「Add python.exe to PATH」）——**一定要打勾！**
   （忘了打勾，后面启动会失败。）
5. 点 **「Install Now」**，等它装完，点 Close。

> 怎么确认装好了？不用管，下一步的双击脚本会自动检测。

---

## 二、启动：双击 `start.bat`

1. 打开九章算子的文件夹（就是包含 `start.bat` 的那个文件夹）。
2. **双击 `start.bat`**。
3. 黑框会**一闪即隐**（启动器把自己转到后台），随后它自动完成：
   - 精准结束本文件夹上一次启动的旧服务（**不碰电脑上其他 Python 程序**）；
   - 在后台静默拉起 `65496` 端口服务；
   - 等 `/healthz` 真正应答后，**浏览器自动打开** `http://127.0.0.1:65496/e`。

   > 第一次启动会慢一点（要联网装组件，约 1～3 分钟），请耐心等浏览器出现。
   > 如果两分钟后浏览器仍没打开，打开 `data\launcher.log` 看卡在哪一步，
   > 或在同目录命令行执行 `start.bat --run` 让日志直接刷新。

4. 端口**固定为 65496**，不会再顺延换口。若该端口被**别的程序**占用，启动器会弹窗说明
   并停止——它不会误杀那个程序，也不会让你对着未知的旧实例。

> 🛑 **停止后台服务**：在本目录命令行执行 `start.bat --stop`（只停本文件夹的九章算子，不碰别的程序）。
> 直接再次双击 `start.bat` 则是「先杀旧、再起新」的重启动作。
> 关闭浏览器标签**不会**停止后台服务。

---

## 三、填 AI 密钥（想用自动拆题才需要，可跳过）

不填也能用题库、组卷等基础功能，只是「AI 拆题」会显示「Mock 降级」（不出真实结果）。
想用 AI，就按下面做——**只需做一次**。

### 第 1 步：找到配置文件

在九章算子文件夹里，找到一个叫 **`.env.example`** 的文件。

> 如果你**看不到**文件名后面的 `.example`、或看不到任何以点开头的文件：
> 在文件夹窗口顶部点 **「查看」**，勾选 **「文件扩展名」**（Win11）或
> 「显示 → 文件扩展名」（Win10），让电脑显示出完整文件名。

### 第 2 步：复制一份，改名叫 `.env`

1. 右键 `.env.example` → **复制**。
2. 在空白处右键 → **粘贴**。会得到一个「`.env.example - 副本`」。
3. 右键这个副本 → **重命名**，把名字改成 **`.env`**
   （就是「点 + env」三个字符，没有别的）。
4. Windows 可能弹窗问「更改扩展名可能导致文件不可用，是否继续？」→ 点 **「是」**。

> 现在文件夹里应该同时有 `.env.example`（模板，别动）和 `.env`（你的，要改）。

### 第 3 步：用记事本打开 `.env`，填三行

1. 右键 `.env` → **打开方式** → **记事本**。
2. 找到下面这三行，把等号**右边**改成你自己的 AI 信息：

   ```
   JZO_AI_API_KEY=sk-your-api-key-here
   JZO_AI_BASE_URL=https://api.openai.com/v1
   JZO_AI_MODEL=模型名
   ```

   改成（**示例**，用你自己的真实值）：

   ```
   JZO_AI_API_KEY=sk-你从服务商那里拿到的密钥
   JZO_AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
   JZO_AI_MODEL=qwen-plus
   ```

   - **API_KEY（密钥）**：向你的 AI 服务商索取的一串字符。
   - **BASE_URL（接口地址）**：服务商给你的地址。
     常见的两个例子（照抄其一即可）：
     - OpenAI：`https://api.openai.com/v1`
     - 阿里云百炼：`https://dashscope.aliyuncs.com/compatible-mode/v1`
   - **MODEL（模型名）**：服务商支持的模型名字，比如 `qwen-plus`、`gpt-4o-mini` 等。

3. 按 **Ctrl + S** 保存，关掉记事本。

> 🔒 **`.env` 里只有你自己的密钥，它不会被上传、不会进版本库**（程序已设置好拦截）。
> 别的字段（`JZO_LOCAL_TOKEN` 等）**保持原样、不用动**——留空让程序自动生成最安全。

### 第 4 步：重启生效

改完 `.env` 后，直接重新双击 `start.bat`（它会先停旧进程再起新进程）。
打开 `http://127.0.0.1:65496/e`，看左栏「模型 Provider」那一行：

- 🟢 **绿色「真实模型 · 模型名 · 接口主机」** = AI 接通了，可以用。
- 🔴 **红色「Mock 降级」** = 还没接通，检查上面三行有没有填对、有没有重启。

## 四、装插件（拖拽即可，无需重启）

九章算子的很多功能（卡片渲染、导入、组卷等）是「插件」。插件就是一个**普通的 zip 压缩包**，解压后拖进文件夹就装好了。

### 装一个插件：

1. 你拿到一个插件压缩包，比如 `org.example.card.zip`。
2. **右键**这个 zip → **全部解压缩**（用 Windows 自带的就行，或任意解压软件）。
   解压后得到一个**文件夹**，名字和插件 id 一样，比如 `org.example.card`，
   里面有一个 `plugin.json` 文件。
3. 打开九章算子文件夹里的 **`plugins`** 文件夹。
4. 把刚解压出来的**整个插件文件夹**（`org.example.card`）**拖进 `plugins` 里**。
5. 完成！回到浏览器**刷新页面**即可看到新插件，**不用重启、不用联网、不用注册**。

> 拖好之后，`plugins` 文件夹里应该是这样：
> ```
> plugins\
>   ├── org.jiuzhang.classic-card\   ← 自带的示例插件
>   └── org.example.card\            ← 你刚拖进来的
>         ├── plugin.json
>         └── dist\
> ```
> ⚠️ 注意：拖进去的必须是**含有 `plugin.json` 的那一层文件夹**，
> 不要把 zip 直接丢进去，也不要多套一层文件夹。

### 卸载一个插件：

在 `plugins` 文件夹里，把对应的插件文件夹**删掉**即可。

### 去哪找插件？（插件索引页）

1. 浏览器打开 `http://127.0.0.1:65496/plugins`。
2. 如果别人给了你一个「插件清单地址」（以 `plugins.json` 结尾的网址），
   把它**粘贴**到输入框，点拉取，就能看到有哪些插件、各自的下载地址。
3. 你自己点地址下载 zip，再按上面「装一个插件」的步骤拖进去。

> 九章算子**不会内置任何插件市场、不会自动下载**。清单地址必须由你亲手粘贴，
> 下载和解压永远由你亲手做——这是为了防止「跑路」（内置源失效你就用不了了）。

## 五、界面速览

启动后，浏览器里主要有这几个页面：

| 页面 | 地址 | 干什么 |
|------|------|--------|
| 工作台 | `http://127.0.0.1:65496/e` | 打开就是它：选任务、发 AI 指令、装插件 |
| 关于底座 | `/about` | 底座介绍页：设计原则与各只读契约入口 |
| 插件索引 | `/plugins` | 粘贴清单地址、浏览可用插件 |

> 首次启动时，底座会自动装好内置的「示例题库」插件（5 道高中数学示例题）。
> 在工作台对话框输入「拆分第一题」就能直接体验。

> 地址固定为 `65496`，`/e` 是老师唯一的标准入口（与根地址同页）。
> 浏览器永远不会被带到别的端口：端口被外部程序占用时，启动器会直接报错而不是换口。

## 六、你的数据在哪？怎么备份？

- 你所有的题目，都存在九章算子文件夹里的 **`data`** 文件夹中（明文 SQLite，不加密）。
- **备份**：把整个 **`data`** 文件夹**复制**一份存到别处（U 盘、网盘都行）。
- **换电脑/恢复**：把备份的 `data` 文件夹拷回原位置即可。
- 卸载九章算子**不会**销毁你的 `data`，题目永远是你自己的。

## 七、常见问题（FAQ）

**Q1：双击 `start.bat` 后黑窗口一闪就没了？**
多半是没装 Python，或装 Python 时**没勾「Add Python to PATH」**。
解决：重新运行 Python 安装包 → 选「Modify」→ 勾上「Add Python to PATH」→ 完成后再双击 `start.bat`。

**Q2：黑窗口提示 `[ERROR] Dependency installation failed` / 装依赖失败？**
`start.bat` 会自己换源重试（默认源 → 国内镜像 → 官方源），三级都失败才会报这个错。
请检查网络，然后**再双击一次 `start.bat`**。如果公司网络有限制，换个网络（如手机热点）再试。

> **特别提示（国内镜像）**：若黑窗口里出现 `No matching distribution found for fastapi==...`，
> 多是你电脑上的 pip 默认走了某个国内镜像（如清华源），而该镜像一时还没同步到这个版本。
> 新版 `start.bat` 已会自动改用官方源重试；如需手动，在九章算子文件夹里打开命令行执行——
>
> ```
> .venv\Scripts\python.exe -m pip install -i https://pypi.org/simple -r requirements.txt
> ```
>
> 装完再双击 `start.bat`。（这三个组件的版本号是有效的，官方源一定能装上。）

**Q2.5：启动器弹出的错误提示说 pip 修不好？**
`start.bat` 会自己用 ensurepip 修好；修不好会自动重建 `.venv` 再修一次。
只有最终弹窗提示依赖装不上才需要人工介入：
重装 Python 3.10+（勾「Add to PATH」、保留 pip 选项），删掉文件夹里的 `.venv`，再双击 `start.bat`。
具体原因看 `data\launcher.log`。

**Q3：浏览器打开是「无法访问此网站 / 连接被拒绝」？**
说明服务还没起来或已停止。先等几秒再刷新；仍不行就看 `data\launcher.log` 与
`data\uvicorn-65496.err.log`，里面会写卡在哪一步。

**Q4：浏览器地址怎么不是 65496？**
标准入口只有一个：`http://127.0.0.1:65496/e`。启动器会把浏览器直接带到这个地址，不会再换口。
如果你手动打开了别的端口，那多半是旧书签——关掉它，以启动器自动打开的页面为准。

**Q4.5：双击后提示「65496 被其他程序占用」？**
说明有**非九章算子**的程序占着这个端口。启动器不会误杀它。请关掉那个程序后再双击 `start.bat`；
若不知道是谁，可在命令行执行 `netstat -ano -p TCP | findstr :65496` 查 PID 再到任务管理器核对。

**Q5：工作台左栏显示红色「Mock 降级」？**
AI 没接通。请检查第三节：`.env` 是否建好、三行密钥/地址/模型名是否填对、**填完是否重启过**。
不填 AI 不影响题库等基础功能。

**Q6：我改了 `.env` 但没生效？**
改完 `.env` 必须**重新双击 `start.bat`**（先杀旧进程、再起新进程）才会生效。

**Q7：插件拖进去了但页面没反应？**
① 确认拖进 `plugins` 的是**含 `plugin.json` 的文件夹**，不是 zip、也没多套一层。
② 刷新浏览器页面。③ 到 `/plugins` 或首页看插件是否被识别（不合规的插件会被列出原因）。

**Q8：怎么彻底停止九章算子？**
在本目录命令行执行 `start.bat --stop`。它只停本文件夹启动的九章算子，不碰别的程序；
下次要用再双击 `start.bat`。

**Q9：会不会偷偷上传我的题目？会不会突然收费？**
不会。题库、组卷、渲染、导入导出全部在你本机跑，断网可用。
只有「AI 拆题」这一步会连**你自己在 `.env` 里填的**那个 AI 地址；不填或断网，它就显式降级，绝不偷偷上传、绝不弹窗催费。这是写进项目规范的硬承诺。

## 八、给内测同事的一句话总结

> 装一次 Python（记得勾 Add to PATH）→ 双击 `start.bat` → 黑框一闪即隐，浏览器自动打开就能用。
> 想用 AI 就用记事本改 `.env` 里那三行再重启；想加功能就把插件解压后拖进 `plugins` 文件夹。
> 你的题目都在 `data` 文件夹里，随时拷走。
