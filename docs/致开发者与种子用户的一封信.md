# 致开发者与种子用户的一封信

**公元 2026 年 10 月 25 日，九章算子 v1.0.0 正式版落地。**

写这封信不为公告，只为把三件事说清楚：这东西为什么长这样、你能对它做什么、我们之间有什么约定。

## 一、它为什么长这样

我是一名独立数学教师，教龄十余年。过去几年我用过不少题库软件，也吃过不少亏：数据存进别人的云端，导出要会员；工具停服，攒了五年的题一夜变成一堆打不开的加密文件；想加一个自己顺手的功能，得等厂商排期，或者自己动手改源码——而源码根本不开。

九章算子就是对着这些亏做出来的，所以它的每一条架构选择都指向同一件事：**教师必须永远是工具的主人。**

- **纯本地，防跑路。** 题库是本机 `data/` 里的明文 SQLite，题目结构是公开的 JSON Schema。断网能用，拷走就能带着全部家当换机器；哪天这个项目没了，你的题一道不少，任何工具都还读得动。
- **万物皆插件。** 底座只做鉴权、导航、数据总线与插件生命周期，录题、题库、组卷、讲义、AI 对话全是插件。不顺手就换掉那一个插件，不用改底座一行代码。
- **出网由你点头。** 没有内置插件市场，没有后台轮询。每一次联网下载，都必须是你在界面上当场点了一次按钮发起的；不点，底座一个字节也不往外发、也不往里拉。
- **免费不可撤销。** 免注册、免卡密、无签名校验、无联网回连、无远程禁用——这不是承诺的口号，是写进规范（PLUGIN_SPEC §1.1）和代码里的硬约束：底座压根没有「授权校验」这类分支，也不给插件提供这类接口。

## 二、你能对它做什么

**给老师（种子用户）**：解压 → 双击 `start.bat` → 浏览器自动打开工作台。官方七支插件（题库引擎、真题题库、录题工作台、组卷排版、讲义排版、AI 助手、数据看板）在「插件索引」页点【拉取清单】就能看到，点【在线安装】才下载那一个 zip。想配 AI，只在 `.env` 里填你自己的模型网关密钥；不填，AI 那一步显式降级，其余功能照常。

**给开发者**：插件就是一个 zip，顶层目录名等于清单里的 `id`，解压即用，禁止任何专属后缀。三件必读：

1. [PLUGIN_SPEC.md](PLUGIN_SPEC.md)——契约的唯一事实来源；
2. [PLUGIN_SPEC.md §8「如何用 AI 写插件」](PLUGIN_SPEC.md)——可以直接整段复制给任何大模型的提示词，让 AI 代写也不踩架构红线（逐条接口速查见 [API_REFERENCE.md](API_REFERENCE.md)）；
3. [`examples/template-plugin/`](../examples/template-plugin/)——最小可运行模板，改三处就变成你自己的插件。

想让别的插件调用你的能力，就在清单里登记命令（`contributes.commands`），运行时经宿主的能力路由字典转发；插件之间永远不直接调用、不共享全局状态、不互相翻 iframe。

## 三、我们之间的约定

1. **干净房间。** 全部代码从零手写，不复用任何历史项目的源码、样式、数据或文档。这条对贡献者同样生效。
2. **你的数据是你的。** 发行包里永远不含真题库；更新只覆盖插件代码目录，绝不动 `data/`；卸载不销毁、不加密、不留水印。
3. **坏了不能拖累你。** 单个插件加载失败、渲染超时、连续报错，底座隔离它并继续可用。
4. **有账必认。** 每个版本的真机取证与测试结论都落在仓库里（[`PROJECT_MEMORY.md`](PROJECT_MEMORY.md) 与 `docs/` 里的阶段进度记录），没验证过的部分一律写「未验证」，不用推测冒充证据。

九章算术，算子至简。愿你手里的工具，永远听你的话。

—— 九章算子作者 · MT-Blaze
