# 占位演示插件（org.jiuzhang.placeholder）

官方占位插件，使命只有一个：跑通 v0.5.0 的「拉取清单 → 在线安装 → 插件生效」闭环。

- 类型：renderer（`question.card` 插槽），把题目渲染成一张虚线边框的极简卡片。
- 分发：打成 `examples/placeholder_plugin.zip`，由仓库根 `plugins.json` 索引指向其 Raw 直链。
- 后续官方插件迁入独立的 `jiuzhang-plugins` 仓库后，本插件即完成历史使命，可整目录删除。
