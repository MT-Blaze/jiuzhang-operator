CLEAN ROOM · LOCAL FIRST · PLUGIN HARNESS

装在自己电脑里的
数学题库底座

为独立教师而做。底座只管四件事——鉴权、导航、数据总线、插件生命周期； 题目怎么渲染、怎么导入、怎么组卷，全交给可插拔的「算子」。 你的题存在你自己的硬盘上，断网照样用。

本页是仓库的静态橱窗，纯 HTML + CSS，不含脚本、不发任何网络请求，可直接离线打开。 启动程序后，真正的应用首页在 http://127.0.0.1:8000。

底座不写死、也不自动拉取任何远程下载源——防的就是「作者跑路，软件变砖」。 全仓唯一允许的出网口子，是你在「插件索引」页亲手粘贴的清单地址； 底座只发一次只读 GET，不解压、不安装、不执行。

三步上手，不用敲命令

面向不懂技术的老师。全程只需要「双击」和「用记事本改几个字」。

  1. 装一次 Python

    到 python.org 下载并安装，务必勾选「Add Python to PATH」。 装过一次以后就不用再装。

  2. 双击 start.bat

    弹出一个黑色窗口，它会自动建虚拟环境、装依赖、起服务。 第一次约 1～3 分钟，之后可以完全离线。 

    > [1/4] Virtual environment found.
> [2/4] Installing dependencies ...
> [3/4] Opening your browser ...
> [4/4] Starting server.

  3. 浏览器自动打开

    没自动打开就手动访问下面的地址。 黑色窗口别关——它就是服务本身，关掉即停止。 

    http://127.0.0.1:8000
AI 是可选的。 想用「导入原卷 → 自动拆题」，就把 .env.example 复制成 .env， 用记事本填三行（密钥、接口地址、模型名）再重启；不填也能正常用题库， 只有 AI 那一步显式降级为 Mock，绝不偷偷上传。

插件生态：底座要薄，算子要自由

名字取自《九章算术》——术是通用底座，算是具体解法。 底座定契约与边界，解法交给任何人写的插件。

  • 底座 Harness鉴权 · 导航 · 数据总线 · 插件生命周期 · 安全边界
  • 数据契约question.json 是题目在底座、插件、导入导出之间流转的唯一标准结构
  • 沙箱插件纯 zip 解压拖进 plugins 目录，跑在 iframe 里，只能经 Host API 读写被授权的数据

装插件 = 解压 + 拖拽

拿到一个 org.example.card.zip，右键全部解压， 把含 plugin.json 的那层文件夹拖进 plugins 目录， 刷新页面即可。不用重启、不用联网、不用注册、不用签名。 卸载就是把文件夹删掉。

没有内置市场，是故意的

底座不预置任何插件源。想要清单，就在 /plugins 页 把别人给你的 plugins.json 地址亲手粘贴进去， 底座只读拉一次，把条目列给你看；下载与解压永远由你亲手完成。 源失效了，你已经装好的插件照样能跑。

愿景：一人写算子，众人得利器

手写板书风格的卡片渲染、几何图OCR、按考向组卷、讲义排版、错因统计—— 每一样都该是一个独立插件，而不是一次底座大改。 写插件的人不必碰数据库和密钥，用插件的人不必信任任何人。

坏插件拖不垮底座

加载失败、渲染超时、连续报错都有兜底渲染与隔离记录。 插件的 HTML 禁 <script>、禁内联事件、禁 javascript:、禁远程样式；图片只允许底座托管路径或 asset:// 逻辑地址。

技术边界

刻意保持寒酸的技术栈，是为了让十年后还能一键跑起来。

九章算子 v0.10.0 技术栈与约束
层面选型约束
后端 Python 3.11+ · FastAPI · Uvicorn 异步 handler 内禁阻塞；SQL 必须参数化；删除一律墓碑软删

常见问题

用键盘 Tab 与 Enter 即可展开收起，无需鼠标。

会不会偷偷上传我的题目？会不会突然收费？
不会。题库、渲染、组卷、导入导出全部在你本机跑，断网可用。 只有「AI 拆题」这一步会连你自己在 .env 里填的那个地址； 不填或断网，它就显式降级为 Mock，绝不静默上传、绝不弹窗催费。 这是写进项目规范的硬承诺。
双击 start.bat 后黑窗口一闪就没了？
多半是没装 Python，或装的时候没勾「Add Python to PATH」。 重新运行 Python 安装包 → 选 Modify → 勾上 Add Python to PATH → 完成后再双击。
浏览器提示「无法访问此网站 / 连接被拒绝」？
说明服务没起来或已停止。确认黑色窗口还开着、且里面已经打到 [4/4] Starting server，等几秒再刷新。
提示端口被占用（address already in use / 8000）？
说明你已经开着另一个九章算子了。直接用浏览器访问 http://127.0.0.1:8000 即可，不用重复启动； 或者先关掉之前的黑窗口再双击。
工作台显示红色「Mock 降级」？
AI 没接通。检查 .env 是否已从 .env.example 复制出来、 密钥/接口地址/模型名三行是否填对、填完是否重启过。 不填 AI 不影响题库等基础功能。
插件拖进去了但页面没反应？
① 确认拖进 plugins 的是含 plugin.json 的那层文件夹， 不是 zip 本身、也没多套一层目录；② 刷新浏览器； ③ 到插件索引页看它是否被识别——不合规的插件会被列出具体原因。
为什么不做成网页版或装个客户端就好？
网页版意味着数据在别人服务器上，服务一停你就什么都没了； 本地优先是为了让题库的寿命比任何一个托管平台都长。 打包成桌面客户端的方案在评估中，但前提是不把 Node 构建链拖进主干。
