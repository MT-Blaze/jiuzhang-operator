      拿到 zip 之后

      1. 下载 zip 包（地址在你自己的网络里可达即可，Gitee 附件、阿里云 OSS、腾讯云 COS、自建 Nginx、局域网 http 服务都行）。
      2. 两条安装路，任选其一： 把 zip 直接拖进工作台页面（或在工作台点「安装插件 zip 包」选文件）， 底座过完契约校验自动落地 plugins/； 或者亲手解压，把整个目录放进本仓库的 plugins/（zip 顶层目录名必须等于插件 id）。
      3. 安装成功后侧栏「已安装插件」即时刷新；题库页刷新即可使用。无需注册、无需卡密、无需重启、无需联网。
      4. 卸载：删除 plugins/ 下对应目录即可，底座不在别处留运行态残留。

      索引只回答「有什么、在哪」，不替任何插件背书。插件脚本运行在沙箱 iframe 内， 权限仍受 plugin.json 声明与 PLUGIN_SPEC §1.1 白嫖条款约束： 禁止注册、卡密、试用到期、机器指纹、联网回连激活与远程禁用。
