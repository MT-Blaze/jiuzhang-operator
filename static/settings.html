设置与控制

底座的管理现场只有这一处：左边选分区，右边干活。 工作区（含教材版本）、插件（管理与安装）、模型配置（Provider 与密钥）各占一栏。 底座不自动拉取、不自动更新、不批量下载——每一次出网都由你当场点击发起。

工作区管理

一个工作区就是本机一个独立的 SQLite 库目录，切换即换库、不联网、不注册。 新建的库一律是空壳；「教材版本」决定大纲树按哪套目录过滤， 考向本身是全库并集，换版本不复制题目。

    新建工作区

    导入已有题库数据

    选一个本地 .db（须为 core-bank 七表结构），底座把它挂载成一个新的独立工作区 并切换过去，原文件不受影响、不覆盖任何现有库。用于换机搬迁或从备份恢复。

    插件管理与控制

    已安装插件在这里集中管理：启用/停用（停用即从工作台左栏消失、释放内存，代码与数据原地保留）、 卸载（可选是否保留本地题库数据）、以及安装（下方索引/手动 zip）。 底座不自动装卸任何插件，一切改动都由你当场点。

      在线插件索引

      默认预填官方插件仓库 jiuzhang-plugins 索引的国内可达镜像（gh-proxy 反代）。 主源失败时会自动切换 ghfast / jsDelivr 等备用镜像；改成第三方地址后，底座只访问那一个，不替你换源。

          模型与 API Key 配置

          全仓唯一的模型配置现场（工作台的 Provider 弹窗已退役）。切换即时生效、无需重启； 密钥只写本机 .env 与环境变量——永不入库、永不写日志、永不回显、永不进入插件上下文。

          系统设置

          底座的启动行为由你说了算：打开软件默认落在哪个界面，选一次就记住（落在本机 data/startup.json，与工作区无关、不联网）。 所选插件日后被卸载或停用，底座会优雅回落默认欢迎页并在服务日志与工作台底栏如实说明， 配置原地保留——重新装回或启用后照旧生效。

          关于底座

          九章算子（Jiuzhang Operator）是为独立教师打造的模块化数学题库底座：本地优先、插件自由、 Apache License 2.0 开源。个人版永久免费——免注册、免卡密、无联网回连校验。

          • 底座只负责身份与权限、全局导航、数据总线、插件生命周期与安全边界；业务能力一律由插件提供。
          • 插件格式是标准 zip，解压即用；脚本运行在沙箱 iframe 内，只能通过 Host API 读写被授权的数据。
          • 底座不自动拉取、不自动更新、不批量下载，也不远程禁用任何插件。
