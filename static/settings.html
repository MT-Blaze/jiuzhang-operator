设置与控制

低频操作集中在这里：拉取插件索引、手动安装 zip、查看底座信息。 工作台左栏只留「自由对话」与已安装插件，不再堆叠安装与说明入口。 底座不自动拉取、不自动更新、不批量下载——每一次出网都由你当场点击发起。

在线插件索引

默认预填官方插件仓库 jiuzhang-plugins 索引的国内可达镜像（gh-proxy 反代）。 主源失败时会自动切换 ghfast / jsDelivr 等备用镜像；改成第三方地址后，底座只访问那一个，不替你换源。

      手动安装 zip 包

      自己下载的插件包也可以在这里装：先过 plugin.json 契约校验，再由底座落地 plugins/。只收标准 zip，上限 50 MB；下载或校验失败不会留下半个文件。

      ↓ 把插件 .zip 拖到这里 或点此选择文件。
      也可以把 zip 直接拖进工作台任意位置，由底座全局兜底安装。

      关于底座

      九章算子（Jiuzhang Operator）是为独立教师打造的模块化数学题库底座：本地优先、插件自由、 Apache License 2.0 开源。个人版永久免费——免注册、免卡密、无联网回连校验。

      • 底座只负责身份与权限、全局导航、数据总线、插件生命周期与安全边界；业务能力一律由插件提供。
      • 插件格式是标准 zip，解压即用；脚本运行在沙箱 iframe 内，只能通过 Host API 读写被授权的数据。
      • 底座不自动拉取、不自动更新、不批量下载，也不远程禁用任何插件。
